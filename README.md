## `01` — THE ENGINEER BEHIND THE CODE

Hey, I'm **Vedant Atri** — a developer interested in the intersection of Artificial Intelligence, software engineering, and product development.

My focus is moving beyond isolated AI demos toward systems that can plan, execute workflows, use tools, and deliver useful outcomes.

- `01` Building agentic AI applications and multi-agent workflows.
- `02` Exploring LLM orchestration, MCP, RAG, and evaluation.
- `03` Developing ML systems and experimenting with model monitoring.
- `04` Exploring AI security, privacy, and reliable execution.
- `05` Turning ideas into practical, end-to-end software projects.

<br clear="right"/>

> **My engineering philosophy:** A good AI system isn't just a model that generates an answer. It's a system designed to solve a problem, handle failure, and produce results that can be evaluated.

An ML monitoring project exploring how to identify changes in data and model predictions that can degrade performance without obvious system failures.

- Baseline-to-production comparisons.
- Severity classification and monitoring dashboards.
- Time-window analysis and retraining-trigger concepts.

`Python` `Scikit-learn` `Pandas` `SciPy` `Streamlit`
